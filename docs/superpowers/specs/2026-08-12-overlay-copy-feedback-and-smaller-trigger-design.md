# NextSay 自绘复制提示与小尺寸浮球设计

## 目标

- 将快捷候选复制成功后的系统 Toast 替换为 NextSay 自己绘制的无障碍悬浮提示，避免荣耀等系统拦截 Toast。
- 将绿色浮球从 64dp 缩小到 52dp，减少对聊天页面的遮挡，同时保留点击、长按与拖动能力。
- 不改变 QQ、TIM、QQ Lite 与微信现有的复制、写入和“绝不自动发送”规则。

## 交互

- 用户点击快捷候选且复制成功后，先收起三张候选卡，再显示文本“已复制”。
- 提示使用深色半透明圆角背景和小号白字，显示在浮球靠屏幕内侧的位置。
- 提示窗口不可聚焦、不可触摸，不阻挡聊天页面操作，并在约 800ms 后自动消失。
- 连续复制时取消旧的消失任务并重新计时；离开支持的聊天应用、销毁服务或隐藏全部内容时立即移除提示。
- 复制失败继续使用现有候选区域错误反馈，不显示成功提示。

## 尺寸与定位

- 浮球窗口：52dp × 52dp。
- 浮球图标保留当前编辑图标、绿色圆形表面、涟漪与触觉反馈。
- 提示根据浮球位于屏幕左半边或右半边，显示在其右侧或左侧，并限制在屏幕边界内。
- 浮球位置恢复、拖动边界、快捷候选位置计算全部使用新的 52dp 尺寸。

## 实现边界

- 在 `OverlayWindow` 内维护独立的 copy-feedback overlay view、窗口参数和生命周期。
- 使用可测试的纯 Kotlin 定位策略计算提示位置；Android View 只负责渲染。
- 删除快捷复制成功路径中的 `Toast.makeText`，不申请通知权限。
- 高级面板中已有的其他提示不在本轮范围内。

## 验证

- 单元测试覆盖提示在浮球左右两侧时的定位、屏幕边界约束，以及 52dp 浮球参与定位的结果。
- 运行 Android 全量单元测试、lint 和 debug APK 构建。
- 真机验证 QQ：点击候选后卡片收起、显示“已复制”、写入输入框、不自动发送。
- 真机验证浮球尺寸、点击、长按和拖动仍可用，并检查无崩溃日志。
