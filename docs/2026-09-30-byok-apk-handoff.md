## 已实现

- 每位用户在手机上填写一套 OpenAI 兼容 API URL、自己的 API Key 和模型名称。
- 手机直接调用 `POST <base-url>/chat/completions`；安装后通过手机自己的 Wi-Fi 或移动数据运行，无需开发电脑、ADB 或 NextSay 服务器。
- 密钥由 Android Keystore 加密；测试连接成功后才能保存，修改任何字段都必须重新测试。
- 生成读取当前已保存配置，支持浮窗及输入法，提供三条候选，只写入用户选择的文字，由用户手动发送。
- 报错显示稳定错误代码及诊断 ID，并提供复制诊断信息；诊断页可以导出 UTF-8 文本文件。
- 日志按字段校验和脱敏，移除配置密钥匹配值，不记录对话、草稿、提示词、候选、网络正文或原始异常消息。
- 日志最多保留 200 条、256 KiB、7 天；读取时也清理过期记录。导出缓存最多保留 3 份，清除日志会删除应用自己的缓存副本，失败时显示未完成。

无障碍服务在支持的聊天页变化时会自动在本机读取节点或进行 OCR，更新本地上下文和加密历史；只有主动生成才向配置的模型服务发送脱敏文字。README 已同步说明这一行为。

## 手机上试用

1. 把 APK 传到手机，安装并打开 NextSay。
2. 打开“配置模型服务”，填写服务商地址、自己的 API Key、模型名称。
3. 点击“测试连接”，成功后保存；密钥只需在手机内填写。
4. 开启所需的无障碍服务或 NextSay 输入法。
5. 使用手机自己的网络，分别测试浮窗和输入法生成、选择候选及手动发送。
6. 报错时点击“复制诊断信息”，或打开“诊断日志”→“导出诊断日志”，把导出的 `.txt` 文件发到当前会话用于排查。

这份调试包为本地开发允许 HTTP；建议实际服务填写 HTTPS 地址。正式版配置校验和主 manifest 拒绝 HTTP。

真机还需验收：实际 Keystore 重启/失效行为、与开发电脑断开后的真实服务调用、错误诊断文件检查、OEM 无障碍和输入法、OCR、切换聊天、写入与屏幕适配，以及设备备份/迁移行为。当前没有这些实际执行证据，不将它们标为通过。
