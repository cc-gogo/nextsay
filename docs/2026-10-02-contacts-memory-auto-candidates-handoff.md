# NextSay 0.2.0 交付记录

## 新功能

- 手动模式：浮球展开时点击只收起；收起时点击读取并生成。窗口内“生成新回复”明确刷新。
- 自动模式：先建立基线，只对可靠重叠后新增的对方文字自动生成。浮球仅展开/收起缓存，不重复收费；关闭窗口仍保持关闭，有结果时图标提醒。
- 长按菜单：当前对象自动候选开关、关系与共用要求、对象细节、记忆与备注关联、原详细面板。
- 新增恋人关系；共用关系要求、对象长期资料、本轮临时要求分开。新轮清临时要求，同轮改写保留。
- 本机 UUID 档案、平台/手动账号空间隔离、HMAC 别名索引、加密显示名/正文/资料/记忆。改备注通过用户确认关联，UUID 不变；审计保留原名称及账号空间。已知同名多档不取第一条，需明确选择。
- 本机保存真实观察文字，不把 AI 候选记成已发送。可靠重叠追加；无重叠独立片段，观察时间不冒充发送时间。检索只在当前对象内、最多近期1000条观察记录；手填记忆单独保留。
- 请求文字预算最多约5900字符（不等于token数），近期消息和临时意图优先；资料及相关历史会发送到用户配置的 API。自动候选与使用记忆需要确认费用/数据说明。
- 锁屏/后台/编辑暂停、总暂停、去重与防抖、取消/迟到结果隔离。只生成候选，不自动输入或发送。
- Room 1→2 增量迁移；旧 ciphertext 原样转入新观察表，特殊标题前缀不能误判为迁移标记。旧账号归属须确认。配置、排除保存、浮球位置保持。

## 不闪屏的实现与边界

候选 root 在 Preview/Loading/Results 之间保持附着；读取/等待显示状态并禁用旧候选，完成时一次 UI 布局替换内容，不隐藏/重挂候选窗口。截图不再调用 hideForCapture/restoreAfterCapture；截图前后校验悬浮窗坐标，变化则拒绝该帧，排除悬浮窗文字与气泡区域。

Android 13 无法读到悬浮窗遮住的文字。为保证不通过隐藏窗口造成闪烁，遮挡、无重叠、未知角色或不可靠滚动时保守跳过，可能漏掉自动触发；移动浮球让出聊天区域或手动生成。不能承诺所有手机/画面完全不闪或每条消息都实时触发。

## 使用

1. 覆盖安装 APK，保留原模型 URL/Key/配置，不要卸载旧版。卸载会丢失本机数据库/密钥。
2. 打开微信/QQ 单聊，长按浮球进入档案；还没有识别对象时先手动生成一次（会调用自己配置的 API）。
3. 新建独立对象或确认关联旧档案；先核对账号空间。旧档案显示“旧账号待确认”。同名对象不要靠标题猜人，主动核对/关联。
4. 填关系、对象资料/长期偏好、已确认记忆；根据需要打开保存/使用记忆/自动候选。关系共用要求影响该关系全部档案。
5. 改备注后确认关联原档案，不复制或自动合并实体。切换微信/QQ登录账号，也要切换 NextSay 账号空间。
